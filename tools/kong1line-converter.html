ตัวแปลงโน้ตฆ้องวงใหญ่ บรรทัดเดียว → สองบรรทัด

เงื่อนไขที่รองรับตอนนี้
  1. x/8 — x คือโน้ต 1–7 (หรือ ด ร ม ฟ ซ ล ท), /8 = โน้ตคู่ต่ำห่างไป 8 เสียง (คู่แปด). /n อื่น ๆ = โน้ตคู่ต่ำห่างไป n เสียง (นับรวมตัวเอง เช่น 5/3 → บน ซ ล่าง ม)
  2. x+ — โน้ตที่มี + ต่อท้าย จะไปอยู่บรรทัดล่าง (บรรทัดบนเว้นเป็น -)
  3. x* = เสียงสูง, x. = เสียงต่ำ, 8 = 1*, 9 = 2*. รูปแบบ -x.xx หรือ -xx*x* (ตัวแรกต่ำกว่าอีกสองตัวหนึ่งช่วงเสียง) → ตัวแรกอยู่บรรทัดล่าง สองตัวหลังอยู่บรรทัดบน
  4. ปุ่ม เติม + — หาโน้ตรูปแบบ -x/x-x/x -x/x-x. xx-x. xx-x/x แล้วเติม + เป็น -x/x-x/x -x/x-x.+ xx-x.+ xx-x/x (x มี . / * หรือไม่ก็ได้)
ข้อความในวงเล็บ ( ... ) จะไม่ถูกแปลง. โน้ตเดี่ยวอยู่บรรทัดบน. เครื่องหมายอื่น (-, เว้นวรรค ฯลฯ) จะถูกคัดลอกไปทั้งสองบรรทัด
