วิธีพิมพ์โน้ตดนตรีไทย ระบบ 1234 (thmjs)

พิมพ์โน้ตเป็นตัวเลข แล้ว thm.js จะแปลงเป็นตารางโน้ต ด ร ม ฟ ซ ล ท
ตัวอย่างในหน้านี้ แถบสีเทาคือสิ่งที่พิมพ์ ตารางด้านล่างคือผลที่ได้

ความเป็นมา

thmjs เริ่มสร้างเมื่อวันที่ 22 พฤศจิกายน 2566 (github.com/warut92/thmjs) เพื่อให้พิมพ์โน้ตดนตรีไทยลงในไฟล์ html ได้ง่าย ๆ ด้วยตัวเลขบนแป้นพิมพ์ Numpad โดยไม่ต้องทำตารางเองใน Word หรือพิมพ์ตัว ด ร ม ฟ ทีละตัว
หลังจากนั้นในวันที่ 8 ธันวาคม 2566 ได้เริ่มทำเว็บไซต์รวมโน้ตชมรมดนตรีไทยนี้ขึ้น เพื่อให้นักเรียนเปิดดูโน้ตผ่านมือถือได้ทุกที่ ไม่ต้องพกกระดาษโน้ต

2. เสียงสูง เสียงต่ำ

* หลังโน้ต = เสียงสูง เช่น 3* = มํ

-5.-6. -1-2 -3*-5* -9-8

3. ห้อง และการลากเสียง

1 ห้องมี 4 ตัว เว้นวรรคระหว่างห้อง ตัวสุดท้ายของห้องคือจังหวะตก
- = ลากเสียง หรือช่องว่าง
x = ตัวหยุด ถ้าจะหยุดนานขึ้นก็พิมพ์ x เพิ่ม เช่น xx
(ในตารางโน้ต x จะแสดงเป็นตัว x แต่ในตัวแปลงเป็นโน้ตสากลจะเป็นตัวหยุด)

---2 ---3 ---4 ---5 -432 xxxx xxxx xxxx

4. ชื่อเพลง ข้อความ

(ชื่อเพลง) อยู่บรรทัดเดียว = ชื่อเพลง ห้ามเว้นวรรค ให้ใช้ _ แทน
[ข้อความ] = ข้อความตัวเล็ก ใช้บอกท่อน เที่ยว ฯลฯ
_ หรือ \s = ช่องว่าง
% หน้าตัวเลข = ให้แสดงเป็นตัวเลข เช่น %1 (ถ้าไม่ใส่ 1 จะกลายเป็น ด)

(แขกบรเทศ_ชั้นเดียว)
([ท่อน_%1])
-666 -666 -555 -333

5. บรรทัด ตาราง กลับต้น

ขึ้นบรรทัดใหม่ = แถวใหม่
เว้นบรรทัดว่าง = ขึ้นตารางใหม่
// อยู่บรรทัดเดียว = กลับต้น
next อยู่บรรทัดเดียว = ขึ้นหน้าใหม่ตอนสั่งพิมพ์

([ท่อน_%1])
-666 -666 -555 -333 -5-8 -2*-3* -5*-3* -9-8
//

([ท่อน_%2])

6. โน้ตตัวเล็ก [ ]

โน้ตในวงเล็บเหลี่ยม (ไม่เกิน 5 ตัว) จะแสดงตัวเล็กและมีเส้นโค้งด้านบน
[ ] = ยาวครึ่งหนึ่ง (2 ตัว = 1 ช่อง)
[[ ]] = ยาว 1/4 (4 ตัว = 1 ช่อง)
ถ้าแปลงเป็นโน้ตสากลโดยตั้ง 1 ตัว = เขบ็ต 1 ชั้น โน้ตใน [ ] จะเป็นเขบ็ต 2 ชั้น ใน [[ ]] เป็นเขบ็ต 3 ชั้น

--[12]3 --[23]5 --[35]6 --[56]8

7. เสียงคู่

พิมพ์ / ตามด้วยตัวเลขหลังโน้ต = ตีคู่พร้อมกัน ตัวเลขจะอยู่ใต้โน้ต สำหรับโน้ตประเภทเครื่องตี
เช่น 8/8 = ดํ คู่ 8, 5/4 = ซ คู่ 4
เลข 10–16 ใส่วงเล็บ เช่น 3*/(10)
ทางลัด $ = /8, f = /4
ถ้ามี * หรือ . ให้พิมพ์ก่อนทับ เช่น 3*/8

-5/4-8/8 --93*/8 -3*/6-3*/8 -9/8-8/8
-3/2-7. 32/4-3/4 -6/8-5. 55-6/8
-234 -6-3 -6/5-4 32-7/8

8. เครื่องหมายต่าง ๆ

พิมพ์ต่อท้ายโน้ต ใส่ได้ 1 เครื่องหมายต่อโน้ต 1 ตัว

ซอ
{ = คันชักออก, } = คันชักเข้า
\๑ ถึง \๙, \ช \ก \น = ตำแหน่งนิ้ว (บนโน้ต)
\i \ii \iii = ตำแหน่งนิ้วเป็นเลข 1 2 3 (บนโน้ต), /i /ii = ใต้โน้ต

-1{-2} -3\๑-5\๒ -6\ii-5\i -3/ii-2/i

จะเข้ ขิม
v = ดีดเข้า, ^ = ดีดออก
\+ หรือ /+ = + ใต้โน้ต (สายลวดจะเข้ / มือขวาขิม)

-1v-2^ -3v-5^ -6\+-5 -3/+-2

อื่น ๆ
+ = โน้ตบวก, = = โน้ตลบ, o = โน้ตกลาง
t = พรม
q ใส่หน้าโน้ต สำหรับเป็นเครื่องหมายพิเศษ = 🏵 เช่น q5

-1+-2= -3o-5t -6-q5 ---1

10. ใช้ในหน้าเว็บ

ใส่โน้ตใน <div id="thm"> แล้วเรียก thm.js ท้ายหน้า ดูตัวอย่างที่ 0-blank_tmp.html

<link rel="stylesheet" href="https://warut92.github.io/thmjs/thmjs.css">

<div id="thm">
(ชื่อเพลง)
([ท่อน_%1])
-666 -666 -555 -333
//
</div>

<script src="../scripts/thm.js@0.0.2"></script>
