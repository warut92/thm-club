ตัวแปลงโน้ตดนตรีไทย ดรมฟ (thmjs) เป็นโน้ตสากล ผ่านระบบ ABC

วิธีใช้และรูปแบบโน้ตที่รองรับ
  • 1-7 = ด ร ม ฟ ซ ล ท, 8 = ดํ, 9 = รํ
  • * หลังโน้ต = เสียงสูง (ใส่ซ้ำได้), . หลังโน้ต = เสียงต่ำ
  • - = ลากเสียง หรือ เงียบ (เลือกได้ด้านล่าง)
  • เว้นวรรคคั่นห้องละ 4 ตัว ตัวสุดท้ายของห้องคือจังหวะตก
  • (ชื่อเพลง) = ชื่อเพลง (ขึ้นเพลงใหม่), ([ท่อน_%1]) = ข้อความกำกับท่อน
  • // = กลับต้น (แปลงเป็นเครื่องหมายย้อน |: ... :|)
  • เครื่องหมายประกอบ เช่น ^ v { } + = o t, ตำแหน่งนิ้ว \๑ /8 จะถูกข้ามไป
  • บรรทัดที่มีตัวอักษรไทย (เช่น โน้ตหน้าทับ) จะถูกข้าม
