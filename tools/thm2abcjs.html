ตัวแปลงโน้ตดนตรีไทย ระบบ 1234 (thmjs) เป็นโน้ตสากล ผ่านระบบ ABC (รุ่นทดลอง)

วิธีใช้และรูปแบบโน้ตที่รองรับ

อ่านวิธีพิมพ์โน้ตแบบละเอียดได้ที่ คู่มือการพิมพ์โน้ต thmjs

  • 1-7 = ด ร ม ฟ ซ ล ท, 8 = ดํ, 9 = รํ
  • * หลังโน้ต = เสียงสูง (ใส่ซ้ำได้), . หลังโน้ต = เสียงต่ำ
  • - = ลากเสียง หรือ เงียบ (เลือกได้ด้านล่าง)
  • x = ตัวหยุด 1 ช่อง, พิมพ์ x ติดกันเพื่อหยุดยาวขึ้น เช่น xx = 2 ช่อง
  • [ ] = โน้ตในวงเล็บยาวครึ่งหนึ่ง (2 ตัวเท่ากับ 1 ช่อง), [[ ]] = ยาว 1/4 (4 ตัวเท่ากับ 1 ช่อง) — แสดงเส้นโค้งคลุมกลุ่มโน้ต เช่น -5[65]3, -[[1235]]-5
  • เว้นวรรคคั่นห้องละ 4 ตัว ตัวสุดท้ายของห้องคือจังหวะตก
  • (ชื่อเพลง) = ชื่อเพลง (ขึ้นเพลงใหม่), ([ท่อน_%1]) = ข้อความกำกับท่อน
  • // = กลับต้น (แปลงเป็นเครื่องหมายย้อน |: ... :|)
  • /เลข หลังโน้ต = เสียงคู่ (ขั้นคู่) ตีพร้อมกัน เช่น 8/8 = ดํ คู่กับ ด (คู่ 8), 5/4 = ซ คู่กับ ด (คู่ 4), เลขสองหลักใส่วงเล็บ /(10); ทางลัด $ = /8, f = /4 — แปลงเป็นโน้ตคู่ (คอร์ด) ในโน้ตสากล
  • เครื่องหมายประกอบ เช่น ^ v { } + = o t, ตำแหน่งนิ้ว \๑ \iii จะถูกข้ามไป
  • บรรทัดที่มีตัวอักษรไทย (เช่น โน้ตหน้าทับ) จะถูกข้าม
